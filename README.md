## 八、几个常被问到的问题

**Q1：CN2 GIA 和 CN2 GT 到底差多少？**
GT 是 CN2 的"普通版"，走的是 AS4809 但不带 GIA 优化，晚高峰容易拥堵；GIA 是"全球互联网接入"专线，全程走 AS4809 优质路由，延迟稳定、丢包率低。直白说，GIA 晚高峰依然能跑，GT 晚高峰基本废。所以你才会看到"便宜CN2 GIA VPS"比"便宜CN2 GT VPS"贵一截。

**Q2：ByteVirt 算 DMIT 套娃吗？**
某种意义上是的——机房在 DMIT 那边，但销售、客服、套餐设计都是 BV 自己做的。这不算"贴牌"，更像是 BV 批发 DMIT 的机柜资源再零售。对最终用户来说，线路质量是一致的，差异主要在客服体系和套餐灵活度上。

**Q3：联通用户值得买吗？**
联通出方向不走 CN2 GIA，所以延迟会比电信和移动用户高一些。如果你的访问者主要是联通用户，可以考虑 BV 的 LA-China Optimized Elite 系列（AS9929 + CN2 混合路由），价格比 CN2 GIA 略低，联通体验更好。

**Q4：512MB 真的够用吗？**
跑代理、SSH、轻量博客够用；跑 Docker 多容器、Java、MySQL 这种吃内存的就有压力。建议系统装 Debian 或 Alpine，别装 Ubuntu Desktop 那类重型发行版。

**Q5：能退款吗？**
官网 Terms of Service 写明新订单有退款窗口（具体时长以官网当时政策为准），但循环续费订单一般不退。建议先月付试一周，确认线路和延迟都满意了再转年付锁价。
